# Мух Цокотух

Первая играбельная Android-версия: добрый 2D-платформер о мухе в очках и красном шарфе. Собирайте монеты, избегайте мухобоек, паутины и липких луж, а затем обменяйте 10 монет на сладкий лимонад в киоске.

## Управление

- ◀ / ▶ — идти
- Прыжок — прыжок и короткий взмах крыльями в воздухе
- На киоске нажмите «ЛИМОНАД», если собрано 10 монет

## Сборка

Нужны JDK 17 и Android SDK. Откройте проект в Android Studio или выполните `gradle :app:assembleDebug`. GitHub Actions прикрепляет `app-debug.apk` к каждому запуску workflow **Build debug APK**.

## Что есть в демо

- Оригинальная рисованная сцена и анимированный герой
- Сенсорное управление, камера и HUD
- Монеты, опасности и условия победы
- Синтезированные короткие звуки без сторонних файлов
